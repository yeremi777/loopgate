# Safety rules live in loopd, not in prompts

Jobs run the user's own `land` skill, which can merge, and an issue author can write text that argues a model past any prompt. So every safety rule sits where the model cannot reach it: each Claude Code stage runs sandboxed with no network path to GitHub, `loopd` decides pass or fail only from the verify command's exit code, and `loopd` itself pushes the gated branch and opens the PR with `gh pr create --draft`. `land` still writes the PR body and moves the spec's lasting content, but offline. The rejected options were a restricted `land` prompt, and opening GitHub to the `land` stage behind deny rules; deny rules match command prefixes only, and the user's `gh` token can merge through `gh api`.
