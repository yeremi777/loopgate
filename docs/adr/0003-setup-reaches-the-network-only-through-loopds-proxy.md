# The setup command reaches the network only through loopd's proxy

The verify command runs offline (ADR 0002), so a stack whose dependencies live in the worktree, such as `node_modules` or `.venv`, needs a setup command that installs them first, and that command runs code the model can change: `postinstall` scripts and the manifest itself. It runs under the verify command's Seatbelt profile, which lets it reach only localhost and resolve no names, with `HTTPS_PROXY` set to a proxy in `loopd` that tunnels only to the Loop's `network` domains, the same reach the Claude Code stages already have; a tool that ignores the proxy fails closed. The rejected options were open network with credentials blocked, which lets the setup command send anything it reads to any host; forcing `--ignore-scripts`, which `loopd` cannot enforce on a command string and which does not cover Python builds; and running setup through Claude Code's sandbox, which puts a model, or a separate runtime dependency, into a deterministic step.
